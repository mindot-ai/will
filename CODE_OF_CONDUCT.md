# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be constructive, assume good faith. Harassment,
discrimination, and personal attacks are not tolerated in any project space
(issues, PRs, Discussions, or community channels).

Reports: **conduct@mindot.io**. Reports are handled confidentially by the
maintainers.
